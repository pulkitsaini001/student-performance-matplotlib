Student Performance Analysis Using Matplotlib
About the Project

This project analyzes student performance using Python and Matplotlib.

The project uses different types of charts to understand student marks, study hours, subject performance, monthly performance, marks distribution, and pass/fail results.

Technologies Used
Python
Matplotlib
Charts Used
Scatter Plot — Study Hours vs Marks
Horizontal Bar Chart — Subject Marks Comparison
Histogram — Marks Distribution
Pie Chart — Pass vs Fail
Line Chart — Monthly Performance
Bar Chart — Student Marks
Subplots — Final Student Performance Dashboard
Analysis Performed
Study Hours vs Marks

A scatter plot is used to visualize the relationship between study hours and marks.

Subject Marks Comparison

A horizontal bar chart is used to compare marks across different subjects.

Marks Distribution

A histogram is used to understand how student marks are distributed.

Pass and Fail Analysis

A pie chart is used to show the proportion of passed and failed students.

Monthly Performance

A line chart is used to visualize changes in average marks over different months.

Student Marks

A bar chart is used to compare individual student marks.

Final Dashboard

Multiple charts are combined using Matplotlib subplots to create a simple student performance dashboard.

How to Run
Install Python.
Install Matplotlib:
pip install matplotlib
Run the Python file:
python student_performance.py
